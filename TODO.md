# Superstore Sales Data Analytics & Forecasting Project - Task Plan

## Goal
Build a self-contained, runnable data analytics & data science project that performs
end-to-end analysis of Superstore sales data (cleaning -> EDA/visualization -> time-series forecasting).

## Steps
- [x] Plan project structure and scope
- [x] Create `requirements.txt`
- [x] Write sample data generator (`data/generate_sample_data.py`)
- [x] Generate sample Superstore dataset (`data/superstore.csv`)
- [x] Write analytics module (`superstore_analysis.py`): cleaning, feature engineering, EDA visualizations
- [x] Write forecasting module (`superstore_forecast.py`): monthly sales/profit time-series forecasting
- [x] Run the full pipeline end-to-end
- [x] Verify outputs (charts, forecasts, summary stats)
